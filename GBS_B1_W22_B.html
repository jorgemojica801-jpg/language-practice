Grammar in Practice

Passive Voice & Temporal Framing · Zero & First Conditionals — Supply Chain contexts from "Are we running out of things?".

Structural Formulas

Passive Voice Formula

Subject + [To Be] + Past Participle (+ by Agent)

Example: "The film was shot in 1997."

Active Contrast

Subject + Action Verb + Direct Object

Example: "The director shot the film in 1997."

Temporal Framing Timeline

PAST ACTION (Completed)

"The movie was filmed in New Zealand."

Focus on the production process that finished in the past.

PRESENT STATE (Permanent/Continuous)

"The movie is set in a fictional universe."

Focus on narrative background, state, or setting today.

Conditional Formulas (Supply Chain Lesson)

Zero Conditional — How Systems Work

If + Present Simple, Present Simple

Example: "If a problem occurs anywhere in the supply chain, production stops."

First Conditional — Real Future Possibility

If + Present Simple, will + Base Verb

Example: "If there is a spike in demand, shops will run out of stock."

Cause & Effect Chain

CONDITION (IF / WHEN)

"If there is a spike in demand…"

The 'if' clause never uses 'will' — keep it in the present simple.

RESULT

"…shops run out of stock quickly." / "…shops will run out of stock."

Zero conditional for facts and routines; first conditional for predictions. Result first → drop the comma: "Production stops if a problem occurs."
